# Georgios Lamprou — Labs

Source for the Quarto website intended for `https://labs.georgioslamprou.gr`.

## Local development

Install [Quarto](https://quarto.org/docs/get-started/), then run:

```bash
quarto preview
```

Create a production build with:

```bash
quarto render
```

Rendered output is written to `_site/` and is not committed. Executable articles must be rendered locally and their `_freeze/` results committed before publishing.

## Publishing status

Publishing is intentionally manual-only until the local site, repository creation, and domain activation have each received separate approval. The workflow can be run manually after GitHub Pages is configured; automatic deployment from `main` will be enabled only at the publishing checkpoint.

The website content and source are not currently offered under an open-source license.
